# WasteWise Admin Dashboard

## Overview
WasteWise Admin Dashboard is a web-based management system designed for administrators to monitor and manage waste collection operations. This platform provides tools for tracking waste collection, managing users, and analyzing waste management data.

## Features
- User Management
- Waste Collection Tracking
- Analytics Dashboard
- Report Generation
- Real-time Monitoring

## Tech Stack
- Frontend: React.js
- Backend: Node.js/Express.js
- Database: MongoDB
- Authentication: JWT

## Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/WasteWise-Admin.git
cd WasteWise-Admin
```

2. Install dependencies
```bash
npm install
```

3. Set up environment variables
Create a `.env` file in the root directory and add:
```
PORT=3000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
```

4. Start the development server
```bash
npm run dev
```

## Usage
- Access the admin dashboard at `http://localhost:3000`
- Login with admin credentials
- Navigate through different sections using the sidebar menu
